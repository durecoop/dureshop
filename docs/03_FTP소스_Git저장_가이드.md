## 2. FTP 소스를 Git에 저장하는 이유

| 문제 | Git 사용 후 |
|------|-------------|
| 실수로 파일 삭제 | GitHub에서 복구 가능 |
| 이전 버전으로 돌아가고 싶음 | `git checkout`으로 복원 |
| 누가 뭘 바꿨는지 모름 | 커밋 이력으로 확인 |
| 다른 컴퓨터에서 작업 못함 | `git clone`으로 어디서든 작업 |
| 여러 명이 동시 작업 어려움 | 브랜치로 충돌 없이 작업 |

## 3. 저장 방법 (단계별)

### 방법 A: 필요한 파일만 추가하기 (권장)

> 수정할 파일만 FTP에서 다운로드하여 Git에 추가

#### Step 1: Git 프로젝트 폴더로 이동

```bash
cd C:\Users\이지원\DURE_SHOP
```

#### Step 2: FTP에서 필요한 파일 다운로드

```bash
# 폴더 생성 (없으면)
mkdir -p WEB-INF/jsp/shop/order

# FTP에서 다운로드
curl -u tester2:1234 "ftp://100.100.1.54/WEB-INF/jsp/shop/order/order_step2.jsp" -o "WEB-INF/jsp/shop/order/order_step2.jsp"
```

#### Step 3: Git에 저장

```bash
git add WEB-INF/jsp/shop/order/order_step2.jsp
git commit -m "feat: order_step2.jsp 추가"
git push
```

---

### 방법 B: 폴더 전체 다운로드

> 특정 폴더의 모든 파일을 한 번에 다운로드

#### FileZilla 사용 (GUI 방식)

1. FileZilla 실행
2. 접속 정보 입력:
   - 호스트: 100.100.1.54
   - 사용자명: tester2
   - 비밀번호: 1234
   - 포트: 21
3. 연결 클릭
4. 우측(서버)에서 필요한 폴더 선택
5. 좌측(로컬) `C:\Users\이지원\DURE_SHOP` 으로 드래그

#### 다운로드 후 Git 저장

```bash
cd C:\Users\이지원\DURE_SHOP
git add .
git commit -m "feat: FTP 서버에서 소스 동기화"
git push
```

## 4. 앞으로의 작업 흐름

### 4.1 권장 작업 순서

```
1. 로컬에서 파일 수정
       ↓
2. Git 커밋 (버전 저장)
       ↓
3. GitHub push (백업)
       ↓
4. FTP 업로드 (서버 반영)
       ↓
5. 브라우저에서 확인
```

### 4.2 주의사항

| 하지 말 것 | 해야 할 것 |
|------------|------------|
| FTP에서 직접 수정 | 로컬에서 수정 후 업로드 |
| Git 커밋 없이 FTP 업로드 | 항상 커밋 먼저 |
| 다른 사람 파일 덮어쓰기 | git pull로 최신 확인 후 작업 |
