## 1. 상황 이해하기

### 1.1 우리의 상황

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│    컴퓨터 A     │     │    컴퓨터 B     │     │    컴퓨터 C     │
│   (이지원)      │     │   (김철수)      │     │   (박영희)      │
│                 │     │                 │     │                 │
│  Claude Code    │     │  Claude Code    │     │  Claude Code    │
│       +         │     │       +         │     │       +         │
│     Git         │     │     Git         │     │     Git         │
└────────┬────────┘     └────────┬────────┘     └────────┬────────┘
         │                       │                       │
         └───────────────────────┼───────────────────────┘
                                 │
                                 ↓
                    ┌─────────────────────────┐
                    │        GitHub           │
                    │  durecoop/dureshop      │
                    │                         │
                    │  - 모든 코드 저장        │
                    │  - 변경 이력 관리        │
                    │  - 충돌 방지            │
                    └─────────────────────────┘
                                 │
                                 ↓
                    ┌─────────────────────────┐
                    │      FTP 서버           │
                    │    100.100.1.54         │
                    │                         │
                    │  - 실제 웹사이트 운영    │
                    └─────────────────────────┘
```

### 1.2 핵심 원리

> **GitHub가 중심!**
> 모든 컴퓨터는 GitHub를 통해 코드를 주고받습니다.

```
컴퓨터 A에서 수정 → GitHub에 push → 컴퓨터 B에서 pull로 받기
```

## 2. Claude Code란?

### 2.1 한 줄 설명

> **Claude Code = AI가 코딩을 도와주는 터미널 프로그램**

### 2.2 Claude Code가 하는 일

| 요청 | Claude Code가 하는 일 |
|------|----------------------|
| "order_step1.jsp 수정해줘" | 파일 읽기 → 수정 → 저장 |
| "Git에 커밋해줘" | git add → commit → push 실행 |
| "FTP에 업로드해줘" | curl 명령어로 업로드 |
| "이전 버전으로 롤백해줘" | git checkout으로 복원 |

### 2.3 Claude Code의 특징

```
┌─────────────────────────────────────────────────────────────┐
│                      Claude Code                             │
│                                                              │
│   ✓ 파일을 직접 읽고 수정할 수 있음                           │
│   ✓ Git 명령어를 실행할 수 있음                              │
│   ✓ FTP 업로드를 할 수 있음                                  │
│   ✓ 터미널 명령어를 실행할 수 있음                           │
│                                                              │
│   하지만!                                                    │
│   - 내 컴퓨터의 파일만 수정 가능                              │
│   - 다른 사람 컴퓨터는 접근 불가                              │
│   - GitHub를 통해서만 코드 공유                               │
└─────────────────────────────────────────────────────────────┘
```

## 3. 협업 시나리오

### 3.1 시나리오: 이지원과 김철수가 함께 개발

```
[1일차 - 이지원]

이지원: "order_step1.jsp 리뉴얼해줘"
Claude Code: (파일 수정)
Claude Code: (git commit, push)

→ GitHub에 저장됨


[2일차 - 김철수] (다른 컴퓨터)

김철수: "최신 코드 받아와줘"
Claude Code: (git pull 실행)

→ 이지원이 수정한 코드가 김철수 컴퓨터에 다운로드됨

김철수: "order_step2.jsp 리뉴얼해줘"
Claude Code: (파일 수정)
Claude Code: (git commit, push)

→ GitHub에 저장됨


[3일차 - 이지원]

이지원: "최신 코드 받아와줘"
Claude Code: (git pull 실행)

→ 김철수가 수정한 코드가 이지원 컴퓨터에 다운로드됨
```

### 3.2 그림으로 이해하기

```
         이지원 컴퓨터                    김철수 컴퓨터
              │                              │
1일차         │                              │
              ↓                              │
         step1 수정                          │
              │                              │
              ↓                              │
         git push ─────────→ GitHub          │
                               │             │
2일차                          │             │
                               │             ↓
                               └────→ git pull
                                             │

                                             │

              GitHub ←───────────────── git push
                │

                ↓

              │

```

## 4. 새 컴퓨터에서 시작하기

### 4.1 필요한 것

1. **Git 설치** - https://git-scm.com
2. **Claude Code 설치** - (설치 방법은 별도 안내)
3. **인터넷 연결**

### 4.2 최초 설정 (Claude Code에게 요청)

새 컴퓨터에서 Claude Code를 열고 다음과 같이 요청합니다:

```
"두레생협 쇼핑몰 프로젝트 설정해줘.
GitHub 주소는 https://github.com/durecoop/dureshop.git 이야.
개발 브랜치는 feature/order-renewal 이야."
```

Claude Code가 자동으로:
1. `git clone` 실행 (프로젝트 다운로드)
2. `git config` 설정 (사용자 정보)
3. `git checkout` 실행 (개발 브랜치 전환)

### 4.3 수동으로 하는 경우

```bash
# 1. 프로젝트 다운로드
git clone https://github.com/durecoop/dureshop.git DURE_SHOP

# 2. 폴더 이동
cd DURE_SHOP

# 3. 사용자 설정
git config user.email "durecoop@gmail.com"
git config user.name "durecoop"

# 4. 개발 브랜치로 전환
git checkout feature/order-renewal
```

## 5. Claude Code 작업 흐름

### 5.1 매일 작업 시작할 때

Claude Code에게 요청:
```
"최신 코드 받아와줘"
```

Claude Code가 실행:
```bash
git pull
```

### 5.2 파일 수정할 때

Claude Code에게 요청:
```
"order_step1.jsp에서 버튼 색상을 녹색으로 바꿔줘"
```

Claude Code가:
1. 파일 읽기
2. 코드 수정
3. 파일 저장

### 5.3 수정 완료 후 저장

Claude Code에게 요청:
```
"Git에 커밋하고 GitHub에 올려줘"
```

Claude Code가 실행:
```bash
git add .
git commit -m "style: 버튼 색상 녹색으로 변경"
git push
```

### 5.4 FTP 서버에 반영

Claude Code에게 요청:
```
"order_step1.jsp 파일 FTP에 업로드해줘"
```

Claude Code가 실행:
```bash
curl -u tester2:1234 -T "파일경로" "ftp://100.100.1.54/DureShop/경로"
```

#### FTP 서버 정보

| 항목 | 값 |
|------|-----|
| 호스트 | 100.100.1.54 |
| 사용자 | tester2 |
| 비밀번호 | 1234 |
| 포트 | 21 |

#### FTP 경로 매핑

| 로컬 경로 (DURE_SHOP/) | FTP 서버 경로 |
|------------------------|---------------|
| `WEB-INF/jsp/shop/cart/` | `/DureShop/WEB-INF/jsp/shop/cart/` |
| `WEB-INF/jsp/shop/order/` | `/DureShop/WEB-INF/jsp/shop/order/` |
| `WEB-INF/jsp/shop/main/` | `/DureShop/WEB-INF/jsp/shop/main/` |
| `WEB-INF/jsp/shop/prod/` | `/DureShop/WEB-INF/jsp/shop/prod/` |
| `css/shop/` | `/DureShop/css/shop/` |
| `js/shop/` | `/DureShop/js/shop/` |

> **중요:** FTP 업로드 시 반드시 `/DureShop/` 경로를 붙여야 합니다!

### 5.5 한눈에 보는 흐름

```
┌─────────────────────────────────────────────────────────────┐
│  1. "최신 코드 받아와줘"                                      │
│     → git pull                                               │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  2. "OOO 수정해줘"                                           │
```

## 6. 여러 명이 동시에 작업할 때

### 6.1 기본 규칙

| 규칙 | 이유 |
|------|------|
| 작업 전에 항상 `git pull` | 다른 사람 작업 받기 |
| 작업 후에 바로 `git push` | 내 작업 공유하기 |
| 같은 파일 동시 수정 피하기 | 충돌 방지 |

### 6.2 작업 분담 예시

```
[좋은 예 - 파일 분담]

이지원: order_step1.jsp 담당
김철수: order_step2.jsp 담당
박영희: order.css 담당

→ 각자 다른 파일을 수정하므로 충돌 없음
```

```
[나쁜 예 - 같은 파일 동시 수정]

이지원: order_step1.jsp 수정 중...
김철수: order_step1.jsp 수정 중...

→ 나중에 push하는 사람이 충돌 발생!
```

### 6.3 충돌이 발생하면?

Claude Code에게 요청:
```
"git pull 했는데 충돌이 났어. 해결해줘"
```

Claude Code가:
1. 충돌 파일 확인
2. 양쪽 코드 비교
3. 적절히 병합
4. 커밋

### 6.4 안전한 협업 방법

```
[작업 시작 전]

"나 지금부터 order_step1.jsp 수정할게"
→ 팀원들에게 알림 (메신저, 슬랙 등)


[작업 완료 후]

"order_step1.jsp 수정 완료, push 했어"
→ 팀원들에게 알림
```

## 7. 실제 사용 예시

### 7.1 예시 1: 첫 번째 날 작업

**상황:** 이지원이 새 컴퓨터에서 처음 작업 시작

```
[Claude Code 대화]

나: 두레생협 쇼핑몰 프로젝트 설정해줘.
    GitHub: https://github.com/durecoop/dureshop.git
    브랜치: feature/order-renewal

Claude: 프로젝트를 설정하겠습니다.
        (git clone 실행)
        (git config 설정)
        (브랜치 전환)
        설정 완료했습니다!

나: order_step1.jsp 쿠폰 선택 UI를 카드형으로 바꿔줘

Claude: 파일을 수정하겠습니다.
        (파일 읽기)
        (코드 수정)
        (파일 저장)
        수정 완료했습니다!

나: Git에 저장하고 GitHub에 올려줘

Claude: 커밋하고 push 하겠습니다.
        (git add, commit, push)
        완료했습니다!

나: FTP에도 올려줘

Claude: FTP에 업로드하겠습니다.
        (curl 실행)
        업로드 완료했습니다!
        확인: https://dev.ecoop.or.kr/DureShop/order/orderStep1.do
```

### 7.2 예시 2: 다른 컴퓨터에서 이어서 작업

**상황:** 김철수가 이지원 작업 이어서 진행

```
[Claude Code 대화]

나: 두레생협 프로젝트 최신 코드 받아와줘

Claude: git pull 실행하겠습니다.
        (실행 중...)
        최신 코드를 받았습니다.
        - order_step1.jsp 업데이트됨 (이지원 작업)

나: order_step2.jsp도 같은 스타일로 리뉴얼해줘

Claude: order_step1.jsp 스타일을 참고해서 수정하겠습니다.
        (파일 읽기)
        (코드 수정)
        (파일 저장)
        수정 완료했습니다!

나: 저장하고 올려줘

Claude: Git 커밋하고 push 하겠습니다.
        (완료)
        FTP에도 업로드할까요?

나: 응

Claude: FTP 업로드 완료했습니다!
```

### 7.3 예시 3: 롤백이 필요할 때

**상황:** 수정했는데 문제가 생겨서 되돌리고 싶음

```
[Claude Code 대화]

나: order_step1.jsp 어제 버전으로 되돌려줘

Claude: 커밋 이력을 확인하겠습니다.
        (git log 실행)

        최근 커밋:
        - abc1234: feat: 쿠폰 UI 카드형 변경 (오늘)
        - def5678: feat: 버튼 색상 변경 (어제)
        - ghi9012: 초기 버전 (그제)

        어느 버전으로 되돌릴까요?

나: def5678로 해줘

Claude: 해당 버전으로 복원하겠습니다.
        (git checkout def5678 -- order_step1.jsp)
        복원 완료했습니다.

        Git에 커밋하고 FTP에도 올릴까요?

나: 응

Claude: 완료했습니다!
```

## 8. 자주 하는 질문

### Q1: Claude Code가 다른 사람 컴퓨터 파일을 수정할 수 있나요?

**A: 아니요, 불가능합니다.**

Claude Code는 현재 실행 중인 컴퓨터의 파일만 접근할 수 있습니다.
다른 사람과 코드를 공유하려면 반드시 GitHub를 통해야 합니다.

```
[불가능]
내 컴퓨터 Claude Code → 김철수 컴퓨터 파일

[가능]
내 컴퓨터 → GitHub → 김철수 컴퓨터
```

---

### Q2: 두 명이 동시에 Claude Code로 같은 파일을 수정하면?

**A: 먼저 push한 사람의 코드가 저장됩니다.**

나중에 push하는 사람은 충돌이 발생합니다.

**해결 방법:**
1. 같은 파일 동시 수정 피하기
2. 충돌 발생 시 Claude Code에게 해결 요청

---

### Q3: Git push를 안 하면 어떻게 되나요?

**A: 내 컴퓨터에만 저장됩니다.**

- 다른 사람이 내 작업을 볼 수 없음
- 컴퓨터 고장 시 작업 내용 손실
- 반드시 push까지 해야 안전!

---

### Q4: 실수로 잘못 push 했어요

**A: Claude Code에게 롤백 요청하세요.**

```
"마지막 커밋 취소하고 이전 버전으로 되돌려줘"
```

---

### Q5: FTP에 올렸는데 반영이 안 돼요

**A: 브라우저 캐시 문제일 수 있습니다.**

```
Ctrl + Shift + R (강력 새로고침)
```

또는 브라우저 개발자 도구(F12) → Network → Disable cache 체크
