## 2. 새 컴퓨터에서 개발 환경 설정

### 2.1 Git 설치 확인
```bash
# Git 버전 확인
git --version

# 설치 안 되어 있으면 https://git-scm.com 에서 다운로드
```

### 2.2 GitHub에서 프로젝트 복제
```bash
# 원하는 폴더로 이동 (예: 바탕화면)
cd C:\Users\사용자이름\Desktop

# 프로젝트 복제
git clone https://github.com/durecoop/dureshop.git DURE_SHOP

# 프로젝트 폴더로 이동
cd DURE_SHOP
```

### 2.3 Git 사용자 설정
```bash
# 프로젝트 폴더에서 실행
git config user.email "durecoop@gmail.com"
git config user.name "durecoop"

# 설정 확인
git config --list
```

### 2.4 개발 브랜치로 전환
```bash
# 원격 브랜치 목록 확인
git branch -r

# 개발 브랜치로 전환
git checkout feature/order-renewal

# 현재 브랜치 확인
git branch
```

### 2.5 최신 코드 받기
```bash
# 다른 컴퓨터에서 작업한 내용 받기
git pull origin feature/order-renewal
```

## 3. 일상적인 개발 작업 흐름

### 3.1 작업 시작 전 (매일)
```bash
# 1. 프로젝트 폴더로 이동
cd C:\Users\이지원\DURE_SHOP

# 2. 현재 브랜치 확인
git branch

# 3. 최신 코드 받기
git pull

# 4. 상태 확인
git status
```

### 3.2 파일 수정 후 저장
```bash
# 1. 변경된 파일 확인
git status

# 2. 변경 내용 확인 (선택)
git diff

# 3. 변경 파일 스테이징 (저장 준비)
git add 파일경로

# 예시: 특정 파일만
git add WEB-INF/jsp/shop/order/order_step1.jsp

# 예시: 특정 폴더 전체
git add WEB-INF/jsp/shop/order/

# 예시: 변경된 모든 파일
git add .

# 4. 커밋 (변경사항 저장)
git commit -m "feat: 주문 페이지 리뉴얼"

# 5. GitHub에 업로드
git push
```

### 3.3 커밋 메시지 작성 규칙
```
feat: 새 기능 추가
fix: 버그 수정
style: CSS/디자인 변경
refactor: 코드 리팩토링
docs: 문서 수정

예시:
- feat: order_step1 카드형 레이아웃 적용
- fix: 쿠폰 선택 드롭다운 오류 수정
- style: 결제 버튼 색상 변경
```

페이지별 URL:

- Sources: CSS/JS 파일 확인

## 6. 롤백 (되돌리기) 방법

### 6.1 아직 커밋 안 한 변경사항 되돌리기
```bash
# 특정 파일 되돌리기
git checkout -- 파일경로

# 예시
git checkout -- WEB-INF/jsp/shop/order/order_step1.jsp

# 모든 변경사항 되돌리기 (주의!)
git checkout -- .
```

### 6.2 마지막 커밋 취소 (변경사항 유지)
```bash
# 커밋만 취소, 파일 변경은 유지
git reset --soft HEAD~1
```

### 6.3 마지막 커밋 완전 취소
```bash
# 커밋 + 변경사항 모두 취소 (주의!)
git reset --hard HEAD~1
```

### 6.4 특정 커밋으로 되돌리기
```bash
# 커밋 이력 확인
git log --oneline

# 출력 예시:
# 8425fee feat: order_step1 리뉴얼
# 4fb2dda 초기 커밋

# 특정 커밋으로 되돌리기
git checkout 4fb2dda -- 파일경로

# 예시: order_step1.jsp를 초기 상태로
git checkout 4fb2dda -- WEB-INF/jsp/shop/order/order_step1.jsp
```

### 6.5 브랜치 전체를 이전 상태로
```bash
# master(원본)로 돌아가기
git checkout master

# 다시 개발 브랜치로
git checkout feature/order-renewal
```

### 6.6 FTP 서버 파일 롤백
```bash
# 1. 서버에서 현재 파일 백업 다운로드
curl -u tester2:1234 "ftp://100.100.1.54/WEB-INF/jsp/shop/order/order_step1.jsp" -o order_step1_backup.jsp

# 2. Git에서 이전 버전 가져오기
git checkout 이전커밋해시 -- 파일경로

# 3. 이전 버전을 서버에 업로드
curl -u tester2:1234 -T "파일경로" "ftp://100.100.1.54/서버경로"
```

## 7. 브랜치 관리

### 7.1 브랜치 개념
```
master (원본, 안전한 버전)
  │
  ├── feature/order-renewal (주문 페이지 개발)
  ├── feature/cart-renewal (장바구니 개발)
  └── feature/header-fix (헤더 수정)
```

### 7.2 새 브랜치 만들기
```bash
# 현재 브랜치에서 새 브랜치 생성
git checkout -b feature/새기능이름

# 예시
git checkout -b feature/mypage-renewal
```

### 7.3 브랜치 전환
```bash
# 다른 브랜치로 이동
git checkout 브랜치이름

# 예시
git checkout master
git checkout feature/order-renewal
```

### 7.4 브랜치 목록 확인
```bash
# 로컬 브랜치
git branch

# 원격 브랜치 포함
git branch -a
```

### 7.5 개발 완료 후 master에 병합
```bash
# 1. master로 이동
git checkout master

# 2. 개발 브랜치 병합
git merge feature/order-renewal

# 3. GitHub에 push
git push origin master
```

## 8. 문제 해결

### 8.1 "변경사항이 있어서 브랜치 전환 불가"
```bash
# 방법 1: 변경사항 임시 저장
git stash
git checkout 다른브랜치
git checkout 원래브랜치
git stash pop

# 방법 2: 변경사항 커밋
git add .
git commit -m "임시 저장"
git checkout 다른브랜치
```

### 8.2 "push 거부됨 (rejected)"
```bash
# 원격에 새 변경사항이 있음
git pull --rebase
git push
```

### 8.3 "merge 충돌 (conflict)"
```bash
# 1. 충돌 파일 확인
git status

# 2. 파일 열어서 충돌 해결
# <<<<<<< HEAD
# 내 코드
# =======
# 다른 사람 코드
# >>>>>>> 브랜치명

# 3. 해결 후 커밋
git add 충돌파일
git commit -m "merge 충돌 해결"
```

### 8.4 Git 설정 초기화
```bash
# 사용자 정보 재설정
git config user.email "durecoop@gmail.com"
git config user.name "durecoop"
```

## 9. 유용한 명령어 모음

### 9.1 상태 확인
```bash
git status          # 현재 상태
git branch          # 현재 브랜치
git log --oneline   # 커밋 이력 (간단히)
git log             # 커밋 이력 (상세)
git diff            # 변경 내용 확인
```

### 9.2 저장/업로드
```bash
git add .                    # 모든 변경 스테이징
git commit -m "메시지"       # 커밋
git push                     # GitHub 업로드
```

### 9.3 받기/동기화
```bash
git pull                     # 최신 코드 받기
git fetch                    # 원격 정보만 받기
```

### 9.4 되돌리기
```bash
git checkout -- 파일         # 파일 변경 취소
git reset --soft HEAD~1      # 마지막 커밋 취소 (파일 유지)
git reset --hard HEAD~1      # 마지막 커밋 완전 취소
```

### 9.5 FTP 명령어
```bash
# 업로드
curl -u tester2:1234 -T "로컬파일" "ftp://100.100.1.54/서버경로"

# 다운로드
curl -u tester2:1234 "ftp://100.100.1.54/서버파일" -o 로컬파일

# 목록 확인
curl -u tester2:1234 "ftp://100.100.1.54/폴더경로/"
```
